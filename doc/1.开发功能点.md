# 🚀 一、总体目标

实现一个支持：

* ✅ 用户 ↔ 用户 私聊
* ✅ 用户 ↔ 管理员 聊天
* ✅ 实时在线状态、消息同步、历史记录
* ✅ 可扩展为群聊、客服、通知推送

---

# 🧱 二、系统模块与功能点

## 1️⃣ 用户系统（User Module）

| 功能点                | 说明                          |
| ------------------ | --------------------------- |
| **用户注册 / 登录 / 登出** | 支持邮箱/手机号注册、JWT 登录认证         |
| **用户资料管理**         | 头像、昵称、签名、角色（user / admin）   |
| **在线状态管理**         | 上线、离线、离线时间、最后活跃时间           |
| **Token 鉴权中间件**    | Socket.IO 连接时验证 JWT，拒绝未授权连接 |
| **用户搜索**           | 支持按用户名 / ID 搜索              |
| **好友列表（可选）**       | 支持添加/删除好友关系                 |

> 💡 数据表：`users`

```js
{
  _id: ObjectId,
  username: String,
  passwordHash: String,
  avatar: String,
  role: "user" | "admin",
  online: Boolean,
  lastSeen: Date
}
```

---

## 2️⃣ 聊天连接模块（Socket.IO 层）

| 功能点            | 说明                                        |
| -------------- | ----------------------------------------- |
| **Socket 鉴权**  | 连接时通过 JWT 验证用户身份                          |
| **事件命名规范**     | 统一事件命名，如 `message:send`、`message:receive` |
| **加入用户房间**     | 每个用户一个唯一房间（`socket.join(userId)`）         |
| **在线状态广播**     | 用户上线/离线广播给好友或管理员                          |
| **断线重连处理**     | Socket.IO 自动支持，服务端需记录状态变更                 |
| **消息确认 (ack)** | 每条消息发送后返回状态（delivered / failed）           |

> 💡 核心事件：

```js
// 客户端发送消息
socket.emit("message:send", { to, text }, (ack) => { ... });
// 服务端广播
io.to(receiverId).emit("message:receive", { from, text, time });
```

---

## 3️⃣ 消息模块（Message Module）

| 功能点               | 说明                           |
| ----------------- | ---------------------------- |
| **消息存储**          | 持久化到 MongoDB（消息表）            |
| **发送消息**          | 用户 A → 用户 B                  |
| **接收消息**          | 实时推送到接收方 socket 房间           |
| **历史消息拉取**        | REST API：分页查询会话历史            |
| **已读 / 未读状态**     | 字段或事件维护                      |
| **消息类型**          | text / image / file / system |
| **消息撤回 / 删除（可选）** | 时间内允许撤回或删除消息                 |
| **消息状态更新**        | delivered / read / recalled  |

> 💡 数据表：`messages`

```js
{
  _id: ObjectId,
  senderId: ObjectId,
  receiverId: ObjectId,
  type: "text" | "image" | "file" | "system",
  content: String,
  createdAt: Date,
  status: "sent" | "delivered" | "read"
}
```

---

## 4️⃣ 会话模块（Conversation Module）

| 功能点             | 说明                        |
| --------------- | ------------------------- |
| **用户之间的会话记录**   | 每两人（或群组）一个 `conversation` |
| **最近聊天列表**      | 查询用户参与的最近会话               |
| **未读计数**        | 会话层面统计未读数                 |
| **系统消息 / 通知消息** | 支持系统自动推送消息（如“管理员公告”）      |

> 💡 数据表：`conversations`

```js
{
  _id: ObjectId,
  participants: [userId1, userId2],
  lastMessage: messageId,
  unreadCount: { userId1: 0, userId2: 3 },
  updatedAt: Date
}
```

---

## 5️⃣ 文件上传模块（File Upload Module）

| 功能点      | 说明                        |
| -------- | ------------------------- |
| **上传接口** | 支持上传图片 / 文件，返回 URL        |
| **文件存储** | 本地文件系统 / 阿里云 OSS / AWS S3 |
| **安全限制** | 类型验证、大小限制、防止XSS注入         |
| **消息引用** | 聊天消息中引用文件 URL 或文件 ID      |

---

## 6️⃣ 管理员模块（Admin Module）

| 功能点         | 说明                  |
| ----------- | ------------------- |
| **用户监控面板**  | 查看所有在线用户、消息统计       |
| **用户间对话查看** | 管理员可查看/干预对话内容（权限控制） |
| **广播系统通知**  | 管理员发全局广播消息          |
| **客服会话分配**  | 分配在线客服处理用户消息        |

---

## 7️⃣ 前端功能点（用户侧）

| 功能点                | 说明                 |
| ------------------ | ------------------ |
| **实时聊天界面**         | 支持滚动消息加载、已读标识、时间显示 |
| **消息气泡 UI**        | 自适应布局、图片预览、文件下载    |
| **用户状态显示**         | 在线/离线/正在输入...      |
| **对话列表**           | 最近联系人、未读数          |
| **消息通知**           | 浏览器通知、声音提示         |
| **断线重连提示**         | 连接断开时给出 UI 状态反馈    |
| **表情 / 图片 / 文件发送** | 丰富消息类型支持           |

> 💡 可用技术：

* React / Vue / Next.js 前端
* 使用 `socket.io-client`
* 使用 Redux / Pinia 存储用户状态

---

## 8️⃣ 系统支持功能（可选增强）

| 模块         | 功能点                       |
| ---------- | ------------------------- |
| **Redis**  | 存储用户在线状态 / 消息队列转发（多实例时必备） |
| **日志记录**   | 聊天日志、错误日志、消息流统计           |
| **消息加密**   | 端到端加密（AES）或 TLS 传输加密      |
| **推送服务**   | 移动端或浏览器通知（FCM / Web Push） |
| **敏感词过滤**  | 后端拦截敏感消息、系统警告             |
| **多语言支持**  | 用户界面国际化（i18n）             |
| **离线消息推送** | 用户不在线时存储离线消息，重连后推送        |

# 🧩 九、整体架构示意

```
+----------------------------------------------------------+
|                         前端客户端                       |
| (React/Vue)  socket.io-client / REST API / JWT / UI层     |
+----------------------------------------------------------+
              │
              ▼
+----------------------------------------------------------+
|                     Node.js 服务层                        |
|  - Express + Socket.IO                                   |
|  - REST API (登录/注册/消息历史)                         |
|  - WebSocket 实时通信 (私聊/广播)                        |
|  - JWT 验证中间件                                        |
|  - Redis（可选：消息转发/在线状态）                      |
+----------------------------------------------------------+
              │
              ▼
+----------------------------------------------------------+
|                       MongoDB 数据层                      |
| users / messages / conversations                         |
+----------------------------------------------------------+
```
